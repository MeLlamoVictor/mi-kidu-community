# Contribuir / Contributing

Gracias por ayudar a mejorar Mi Kidu. Abre una issue con el comportamiento esperado, versión del sistema y pasos para reproducir. English and Spanish are welcome.

1. Propón una mejora pequeña y verificable; consulta antes los cambios grandes.
2. Trabaja en un fork y envía una pull request con el problema, cambio y comprobaciones.
3. Ejecuta `swift test`; si cambias interfaces, comprueba la app y documenta el dispositivo o simulador utilizado. No presentes una compilación como validación visual.
4. Mantén el comportamiento local y eficiente. No añadas servicios de pago ni telemetría por defecto.
5. Usa solo datos sintéticos. Revisa capturas, rutas, logs y metadatos: no incluyas nombres reales, cuentas, claves, ubicaciones, datos de menores ni archivos de empresas.
6. Conserva avisos de terceros y aporta la licencia de cualquier recurso nuevo. Las contribuciones se ofrecen bajo la licencia MIT del proyecto, con sus atribuciones correspondientes.

No subas código copiado de un proyecto sin licencia o con términos incompatibles. Las propuestas y el código de forks son entradas no confiables: el mantenedor revisa los cambios antes de ejecutarlos, fusionarlos o desplegarlos. El acceso a datos privados o equipos del mantenedor no forma parte de una contribución.
